# RSSN 的量纲与单位

[English](DIMENSIONS.md) · [内核嵌入接口](KERNEL.zh.md)

RSSN 推导符号计算的量纲，也允许宿主通过内核 ABI 传递带量纲的物理量。本文说明量纲规则、物理量的表示，以及宿主如何检查结果的量纲依据。

## 1. 检查模式

默认使用 `DimensionMode::Advisory`。`compute` 分析输入和结果，返回结果量纲，并在 `Answer::diagnostics` 中记录发现的问题。`DimensionMode::Strict` 遇到阻塞问题时返回 `ComputeError::Dimension`。`Config::bypass_dimension_checks` 保留诊断，并允许计算在发生冲突后继续。使用 `DimensionMode::Off` 可以跳过分析。

严格模式检查调用者提交的表达式。如果 `x` 是长度，`ln(exp(x))` 会被拒绝，因为 `exp` 要求无量纲参数，即使整个表达式可化简为 `x`。

## 2. 基本量纲与指数

默认基本量纲为 `Length`、`Mass`、`Time`、`Current`、`Temperature`、`Amount` 和 `Luminosity`。可为图注册额外量纲。一个量纲是基本量纲的幂之积。指数支持精确有理数、变量和以符号原子为基础的有理函数。符号指数的名称以及 `sin(a)` 等未解释表达式都可以充当原子。通过交叉相乘判断两个有理表达式是否相等。

未声明的符号和函数结果使用量纲变量。统一两个量纲时，先将两者相除，再解出指数为非零有理数的变量，并进行传递代入。剩余具体指数表示冲突，剩余含符号的指数方程表示约束。当方程不足以解出具有符号指数的变量时，该变量保持未知。

`1` 表示无量纲，即空积。`NonMetric` 表示谓词、标签及没有单一标量量纲的容器。零、无穷、空列表和显式绕过规则使用多态量纲 `Any`。一个等价类含有零时，即使其中另一个表达式有具体量纲，也可以采用 `Any`。

## 3. 单位与换算

单位携带量纲、比例和可选的仿射偏置。SI 相干值为 `读数 × 比例 + 偏置`。比例可以精确含有有理数或 π，因此 `sin(quantity(30, deg))` 可以保留为 `sin(π/6)`。`N` 和 `Pa` 等命名导出单位表示同一组基本量纲的幂之积。

原生数值接口直接乘除单个 Float 参考量，保留有符号零，并对次正规结果进行正确舍入。多个参考量的乘积单独累计二进制指数，最后构造输出。

角度、比例和信息单位的量纲为 `1`。角度和比例仍可通过单位类别识别。以 bit 为基准，`bit`、`B` 和 `KiB` 的比例分别是 `1`、`8` 和 `8192`。解析量纲声明时先查单位，再查基本量纲。`base:T` 表示已注册的基本量纲 `T`，而 `T` 表示特斯拉。`base:Length` 对 SI 基本量纲使用同样的显式形式。

符号图使用 `units` 规则集提供的解析器。宿主可以直接传入完整的 `UnitValue`，其量纲、精确比例、偏置和显示信息在物化后保留。只有定义完全一致时才会复用已注册的名称。单位乘积可混用已注册和匿名单位原子。自定义量纲在相干换算和有理次幂中保留。物化会拒绝无效比例分母、不一致的仿射信息、带符号变量的单位量纲及含 π 的偏置。

## 4. 仿射物理量

`degC` 和 `degF` 表示点。点可经由相干原点转换，也可以加上同量纲的差值。例如 `quantity(20, degC) + quantity(2, K)` 将温差加到温度点。两者在内核中的量纲均为 `Temperature`。单位规则拒绝点的倍乘、求幂以及点与点相加。点单位放在复合单位中会导致解析失败。点与点相减保留为符号请求。需要明确求两点差值时，可以先把两个点换算为相干开尔文数值再相减。

## 5. 算子规则

每个标准算子注册一条 `DimRule`。规则可以保留参数量纲、对量纲做乘除、要求量纲相等、开方、要求无量纲，或调用特定领域的 Rust 函数。带求和指标或积分变量的规则还使用其声明量纲。算子注册和内核清单都包含量纲规则。Rust 枚举定义见 [`src/graph/dim.rs`](../src/graph/dim.rs)。

| 表达式 | 量纲规则 |
|---|---|
| `pow(x, y)` | `y` 无量纲，结果为 `x` 的量纲的 `y` 次幂。 |
| `diff(f, x)` · `integral(f, x)` | 将 `f` 的量纲除以或乘以 `x` 的量纲。定积分上下限采用 `x` 的量纲。 |
| `product(f, k, a, b)` | 将 `f` 的量纲提升到 `b - a + 1` 次幂。边界与指标的量纲一致。 |
| `atan2(y, x)` | 两个参数的量纲必须一致，角度结果无量纲。 |
| `sde_wiener(seed, m, steps, h)` | 结果量纲为 `h` 的量纲的平方根。 |
| `sde_levy_areas(seed, h, dw, terms)` | 结果采用 `h` 的量纲，与两个增量相乘一致。 |
| `matexp(A, t)` | 要求 `dim(A) × dim(t) = 1`，适用于速率矩阵乘以持续时间。 |
| `matfun(f, x, A)` | 次数为 `k` 的齐次多项式结果带有系数量纲和矩阵元素量纲的 `k` 次幂。其他函数要求元素无量纲。 |
| 归一化轮廓与分支算子 | 归一化轮廓采用无量纲复变量，因此轮廓积分保留被积函数的量纲。分支角度和索引无量纲。 |
| `abs_sq(z)` · `sqrt_cut(z, angle)` · `from_polar(r, angle)` | 分别取 `z` 量纲的平方、平方根，或保留 `r` 的量纲。角度无量纲。 |
| `arg(z)` · `to_polar(z)` | 相位不带量纲，极坐标的半径保留 `z` 的量纲。 |
| `complex_diff(f, z, n)` · `complex_laplacian(f, z)` | 将 `f` 的量纲除以坐标量纲的相应次幂。 |
| `cball_*` · `cinterval_*` | 圆盘 `list(re, im, rad)` 和矩形区间 `list(re_lo, re_hi, im_lo, im_hi)` 的坐标均无量纲。构造包络前请先归一化带量纲的坐标。 |
| `cauchy_pv(f, x, a, b, pole)` · `hilbert_transform(f, x, y)` | 各坐标的量纲须相容。柯西主值积分乘上坐标量纲，希尔伯特变换保留 `f` 的量纲。 |
| `bromwich_inverse_laplace(F, s, t)` | 要求 `dim(s) × dim(t) = 1`。结果量纲为 `dim(F) × dim(s)`。 |

## 6. 推导过程

分析遍历项的有向无环图，按等价类缓存量纲依据。常量和用户假设提供初值。每个节点根据子节点和算子规则产生候选量纲，然后统一一个等价类的所有成员。如果遍历遇到循环，分析中的等价类暂时提供 `Any`，直到完成遍历。每次计算检查输入与最终结果。`f(x)` 的结果量纲等声明可帮助确定仅凭表达式结构无法求出的变量。

未知量纲、符号约束和量纲冲突分别报告。即使在严格模式中，`Unannotated`、`MixedList` 和项中的 `UnknownUnit` 仍是建议性诊断。量纲声明中的单位文本无法识别时则是阻塞错误。需要具体量纲的宿主应检查分析结果和诊断后再提取物理量。

## 7. 嵌入 API

```rust
let config = Config::new()
    .dimensions(DimensionMode::Strict)
    .dimension("x", "m")
    .dimension_of("f", "m/s^2")
    .define_base_dimension("Currency");
```

`Config::dimension_term` 接受结构化的 `DimExpr`。`Term::dimension` 按当前假设返回量纲，`Term::dimension_report` 还返回分析结果。`Answer::dimension` 保存最终量纲，`Answer::value` 保存相干 SI 数值。`Dimension` 可以脱离图保存，显示形式包括 `Length*Mass/Time^2`、`Length^n`、`1`、`any`、`boolean`，未知变量可显示为 `?x`。可用 `DimError::code()` 与 `DimError::is_blocking()` 对诊断分类。C API 也提供结果及线程级诊断访问接口。[C API 与嵌入契约](KERNEL.zh.md)

## 8. 覆盖契约

`Installer::dim` 为注册的算子附加量纲规则。标准算子的覆盖检查拒绝缺失规则和未获说明的绕过规则。标准声明式重写通过结构化及伪随机量纲组合测试，组合可复现。测试统计跳过的组合，要求规则实际得到检查，并在两端量纲均有效时比较其量纲。领域测试覆盖矩阵、复平面、随机过程和结构化值。[架构与验证](../ARCHITECTURE.md)

## 9. 动态值

内核保留 `Value::Dyn` 中的显式量纲。若内部已经含有物理量，其量纲必须与动态量纲见证一致。非空、同量纲的数值张量在图的叶节点及读回结果中保留元素量纲。量纲混合的数量保持为结构化的符号项。若空张量带有尾部轴长度或非平凡的元素量纲，宿主应持有类型化张量。没有叶节点时，嵌套列表无法重建这些元数据。

核心算术与比较同样提供字面数值签名和符号签名。符号调用可以接收物理量和项句柄。选定的签名决定可接受的参数种类，量纲检查决定结果是否是具体的物理量。

## 10. 单位制

`KernelManifest::unit_systems` 提供四种单位制。每种单位制令指定物理量取值为一，并选定生成其余量纲的基。

| 单位制 | 取为一的物理量 | 其余生成量纲 |
|---|---|---|
| `natural` | `c`、`hbar`、`k_B`、`epsilon_0`，采用 Heaviside–Lorentz 约定 | 能量、物质的量、发光强度 |
| `planck` | `c`、`hbar`、`G`、`k_B`、`4 pi epsilon_0` | 物质的量、发光强度 |
| `atomic` | `hbar`、`m_e`、`e`、`4 pi epsilon_0` | 温度、物质的量、发光强度 |
| `geometrized` | `c`、`G` | 长度、电流、温度、物质的量、发光强度 |

`UnitSystem::reduce` 在有理数域求解量纲分解。取为一的量纲与其余生成量纲共同构成七个 SI 基本量纲的一组基。约简后的量纲仍是 SI 量纲。将相干值除以所选物理量的相应次幂即可得到约简读数。`Reduction::exact_scale` 提供整数次幂的符号比例，`factor_f64`、`to_system` 和 `from_system` 也支持分数次幂。例如电子质量在自然单位制中约为 `0.51099895 MeV`，采用能量量纲。

## 11. 底层数值内核

直接操作 `f64` 存储的算法使用调用者提供的相干值。类型化数值绑定负责为内核输入和结果提供量纲依据。[数值回调的输入、容差与结果](NUMERICAL_CALLBACKS.zh.md)

## 13. 结构化结果与适用范围

`lu`、`qr` 和 `svd` 等分解的结构化结果包含不同量纲的字段。以 `svd` 为例，奇异值带有矩阵元素的量纲，奇异向量无量纲。结构化算子使用 `DimRule::Container`。若把分解结果独立写成混合量纲的嵌套列表，元素没有公用的标量量纲，分析可能报告 `MixedList`。需要逐字段量纲的宿主应使用分解的类型化内核契约。

具有未知单位的项保留符号形式并报告 `UnknownUnit`。可提供已注册单位，也可为匿名单位传入完整的 `UnitValue`。矩阵函数的多项式次数仍是未知符号时，使用无量纲元素，或先代入可确定齐次多项式的次数。在乘以多态零之前若需要验证其中一个子表达式的量纲，请单独分析该子表达式。
