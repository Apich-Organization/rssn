# Mathematical coverage and input policies

[中文](MATH_COVERAGE.zh.md) · [Embedding kernel](KERNEL.md)

Choose an algorithm by its mathematical domain, data representation and error contract. The live manifest lists the operators in a particular build. Rust algorithms and dynamic operators may expose different interfaces to the same implementation.

## Numerical inputs

The checked ABI reports malformed shapes and unsupported domains as an error or a documented IEEE result. This includes empty tensors, inconsistent extents and storage, nonfinite values and out-of-range control parameters. Low-level Rust accessors may require valid indices. Host callbacks have their own Rust panic contract.

| Area | Input and result policy |
|---|---|
| Dense linear algebra | Checked kernels distinguish nonfinite data, shape violations and singular factorizations. `Lu::solve_into` reuses a caller-provided output of the exact dimension and requires a finite right-hand side. Use `pinv`, `lstsq_svd`, `null_space` or `orth` with an appropriate singular-value threshold for rank-deficient problems. |
| Matrix functions | Symmetric `sqrtm`, `logm`, and `powm_psd` use spectral methods and evaluate diagonal matrices entrywise. Positive semidefinite matrices may be singular for square roots and positive powers. Logarithms and negative powers of symmetric matrices require positive eigenvalues. The general real methods use Denman–Beavers or inverse scaling and squaring. |
| Statistics | Sample summaries and tests follow their per-operator missing and empty data policies. Use `percentile` with `p` in `[0,100]`. Survival-function paths retain small tail probabilities without subtracting a CDF rounded to one. Weighted empirical summaries require finite nonnegative weights and positive total weight. Zero-weight samples contribute no mass. |
| Real and complex special functions | Use documented values at poles and on branch cuts. Invalid numeric arguments can yield NaN. Complex `ln_gamma` is an analytic branch. `LambertW` takes a branch index. Complex Bessel J and I accept real order. Fresnel and the complex error-function family preserve scaled tails near floating-point limits. `bessel_i0e` removes the dominant exponential from real modified Bessel I₀ for large arguments. The Kaiser window uses this form to keep its normalization finite. |
| Exact integer algorithms | The 64-bit modular routines use exact wider intermediates. `is_prime` is deterministic for `u64`, and factorization uses Pollard–Brent. `checked_lcm` reports overflow. The discrete logarithm reduces common factors before the coprime baby-step giant-step search, whose table can require space proportional to the square root of the reduced modulus. The symbolic rule set supplies arbitrary-precision algorithms. |
| Quadrature | Tanh–sinh handles integrable endpoint singularities. Adaptive Gauss–Kronrod supplies an error estimate and `integrate_gk_breakpoints` splits at known interior discontinuities or singularities. `levin_adaptive` targets oscillatory integrals with a supplied phase derivative. Simpson and Romberg enforce work bounds. |
| ODE, SDE and roots | Solvers expose method-specific evaluation or step bounds and typed failures. Stiff deterministic problems have implicit methods. SDE methods include drift-implicit options, with different admissible noise structures and a choice of Itô or Stratonovich calculus. Brent requires a sign bracket or an endpoint root. Read the exact solver signature for tolerances and returned diagnostics. |

## Structured and exact domains

- `Complex::sqrt` returns the principal root and uses the imaginary sign at the negative real axis. It preserves representable small components and can return finite roots when the input modulus overflows. The measured native operator takes the square root of the input dimension.
- `AffineIfs` prepares dimensionless affine maps and nonnegative weights once for repeated trajectories with explicit unsigned seeds. The prepared sampler handles finite weights whose sum overflows and returns a typed error if the trajectory leaves the finite range.
- `IrfftPlan` reuses unpacking factors for a fixed real output length. The checked native operator returns samples in the half spectrum's physical dimension. The two length queries distinguish the real sample count from the bin count.
- `Matrix<T>::transpose_into` reuses a mutable destination. It checks the transposed shape before writing. The portable Float and exact matrix operators return owned transposes.
- Polynomial long division advances a coefficient window without moving the remaining input at every step. `Polynomial::try_long_division` skips leading zeros in the divisor, rejects a zero divisor, and recovers finite coefficients through a fused update when a product would overflow.
- Sparse symbolic expansion reuses each expanded opaque subterm within a conversion and preserves generator encounter order. The traversal keeps its pending work on the heap and checks depth across opaque boundaries. Polynomial products reject exponents that exceed their integer representation.
- `Categorical` retains a reusable sampling table for finite nonnegative relative weights. Draws return original zero-based indices and skip zero-weight entries. Equal weights and distributions with a single supported category need no table.
- `permgroup::power_exact` raises a permutation to a signed integer power by reducing the exponent separately for each cycle length. The native operator accepts zero-based images and rejects invalid bijections, degrees above 4,096, and exponent magnitudes exceeding 65,536 bits.
- `ode::solve_fixed_final` shares Euler, Heun and classical RK4 stages with the full fixed-grid solver. It retains only the current state and scratch buffers. The native operator accepts an existing RHS tape, checks its evaluation budget before integrating and restores each final component's physical dimension.
- Diagonal ETDRK4 uses real weights for both fixed and adaptive steps. It reuses stage buffers and selects a stable formula near the origin and far into negative stiffness. The measured native interface accepts an inverse-time diagonal and a nonlinear RHS tape.
- `ChainComplex::betti_mod_p` returns Betti numbers for all degrees after reducing each boundary once. Binary rank uses packed row XOR, and odd prime rank handles signed coefficients and primes across the entire unsigned 64-bit range. Both language operators check the modulus before elimination.
- Homology, sparse exact elimination, machine-word factorization and symbolic primality checks use the same deterministic `u64` witness set. Word modular multiplication uses an exact widened product when the ordinary word product would overflow.
- `crt_general` returns the least nonnegative residue and exact period for compatible congruences with positive moduli. The period is their least common multiple, including when moduli share factors. The coprime `crt` returns the residue alone.
- Large, reasonably balanced coprime CRT systems use a product and remainder tree when the active CPU pool has multiple workers. Each inverse is computed modulo an original modulus, and the tree recombines residues in input order.
- `inverse_erfc` refines extreme tails through a logarithmic residual, including subnormal probabilities. Complex Lambert W uses the imaginary sign to select a side of its negative real cut and preserves small components on the principal branch.
- Equatorial Kerr–Newman initialization chooses a future-directed energy branch and admits compatible orbits inside the stationary limit and beyond the outer horizon. The sampled solver retains the initial and final points and positions at the given step stride. The native physical frame restores both Cartesian axes in length units.
- `kerr::trace_shadow` uses the radial equation for capture and shares the radial force and potential with full ray tracing. The execution pool can trace independent directions concurrently and returns them in image-angle order. The physical `num_native_relativity_trace_shadow` and `num_native_relativity_shadow_analytic` operators both return image-plane lengths in their chosen frame. The analytic operator samples the two halves of the curve and accepts 2 through 2,048 points per half.
- The two-dimensional periodic Ising driver reuses checkerboard scratch. Positive-temperature lattices with multiple sites and a side length of one or two use lazy single-site updates. The online measured entry reports final spins and post-thermalization observables at a fixed stride. A physical frame converts kelvin to exchange-energy units using Boltzmann's constant. A vanishing magnetization series has no Binder value.
- Potts heat-bath sweeps count each neighborhood once and reuse weights by color count. Shifted weights keep the conditional law finite at extreme coupling. Rust callers can reuse a workspace across sweeps, and the native model retains one for repeated calls. The read-only site operator returns a dimensionless probability per color.
- The Gross–Pitaevskii fixed-step solver reuses FFT plans and scratch, and normalizes the initial profile on zero-step or zero-increment requests. Its measured output is a row-major probability density in inverse square length.
- `SchrodingerPlan2D` reuses the signed time increment, potential and kinetic phases across initial wavefunctions. The measured terminal operator keeps inverse-length complex amplitudes and the signed time. A uniform potential can use one Fourier pair for a terminal request with many steps. The sampled API keeps steps 1, 11, 21 and so on.
- Q4 plane-stress assembly uses a single checked local stiffness calculation. Element coordinates are centered and can be uniformly rescaled before quadrature. Assembly processes elements in mesh order and checks connectivity and loads before solving.
- `PreparedTriangles` reuses the geometry, degree-of-freedom layout and quadrature of triangular P1/P2 meshes for independent diffusion–reaction problems. The solver checks the actual residual and uses scaled conjugate gradients for extreme loads. The native plan and problem use the same physical reference frame.
- `PreparedCartesianPoisson` reuses the separable Q1 stiffness spectrum on uniform squares and cubes with zero Dirichlet data. The two- and three-dimensional Poisson entry points use the same sine-basis solve. The prepared interface samples a new source once per quadrature point, and its native adapter restores the references for x-fast nodal output.
- `PreparedLaplaceBem3d` retains the dense collocation operator and factors for fixed boundary kinds. Each solve accepts new values in panel order. A pure-Neumann solve checks the net outward flux and fixes the area-weighted mean potential to zero. The native solution can evaluate interior potential in the mesh's physical dimension.
- `run_fdtd_final_field` advances the legacy transverse magnetic model with two field buffers and returns the electric field at the requested time step. Its checked physical adapter admits one-cell axes, scales the source frequency by the time step `L/(2c)`, and returns the elapsed time. The sampled adapter retains steps 1, 6, 11 and so on.
- The Cartesian Euler and shallow-water solvers reuse the padded state and residual between Runge–Kutta stages. Each directional sweep visits cells in a fixed axis order across worker counts. `RiemannSolver::Hlle` supplies an optional two-wave flux with Einfeldt speed estimates.
- AMR computes independent flux lines on the active CPU pool for large patches. Time subcycling, flux-register accumulation and reflux keep their original order. `ExactRiemann` prepares the ideal-gas wave pattern once for scalar or ordered batch sampling. The measured interface accepts velocity `x/t` and reports density, velocity and pressure separately.
- Molecular-dynamics neighbour searches use a sparse occupied-cell index in large boxes and retain the same order as dense traversal.
- `physics_md::morse_radial` evaluates the shifted Morse energy and signed radial force, including near equilibrium and at zero separation. `num_native_md_morse_radial` exposes both results with the energy and force dimensions of the supplied reference frame.
- `md_engine::Rdf` accumulates each frame's pair counts against its own ideal-gas reference. The native `num_native_engine_rdf_merge_d1`, `num_native_engine_rdf_merge_d2` and `num_native_engine_rdf_merge_d3` operations combine accumulators with matching cutoffs, bins and reference frames.
- `physics_sm::advance_advection_diffusion_3d_modes` advances a reusable x-fastest Fourier field directly in the unnormalized forward FFT convention. `num_grid_sm_advance_advection_diffusion_3d_modes` retains the supplied field reference. The time update uses spectral Forward Euler.
- The 1D method-of-lines solvers read their stencil from the active ODE state. `method_of_lines_1d` evaluates fixed boundary data once. `method_of_lines_1d_timed` samples Dirichlet values and outward Neumann derivatives at the solver's evaluation times and restores the final Dirichlet values. The typed native operator uses measured time for both boundary programs and preserves the returned field's dimension.
- `SseXxz` uses a state-independent number of closed-loop updates when the operator string is nonempty and samples every free spin when it is empty. This changes seeded trajectories from earlier builds. The native sweep budget counts operator and site passes, candidate starting draws and traversed legs. If a sweep or run exhausts its budget after starting, its mutable handle is invalidated.
- The structured continuum multigrid solver reuses one workspace throughout V, W and full multigrid cycles. Its relative residual calculation scales extreme finite values and preserves the ordinary accumulation order. Full multigrid retains both the initial and full-grid residual before correction cycles.
- Symbolic sparse matrix construction and `sp_nnz` index occupied rows when the logical row count is large. The result retains its logical extents, canonical row order and exact cancellation of duplicate entries.
- Symbolic `det` uses the shared rational determinant for exact entries. Large eligible sets of elimination rows run independently on the active CPU pool. Small symbolic determinants retain a division-free expansion with memoized minors.
- The linear ODE eigenring solver composes and divides rational differential operators using prepared derivatives of the right operand's coefficients. Eligible derivative calculations can run on the active CPU pool. Right division updates the exact remainder by decreasing order.
- `ode_asymptotic` converts formal coefficients through the first omitted term and scales its magnitude by the solution prefactor. If the supplied series is exhausted, the final supplied term gives the estimate. `ode_borel` detects exponent gaps across the supplied series and reuses the fixed-point coefficients for its bounded Padé systems. Independent Padé order intervals can use the active CPU pool. The final estimate compares sums in requested order.
- Newton-polygon solutions in `ode_frobenius` share exact coefficients across conjugate field embeddings. The report reuses the prefactors of the two rendered solutions, and numerical evaluation selects branches in the same order.
- Gosper's `antidifference` derives at most two possible polynomial degrees by comparing leading coefficients, including the exceptional degree when two leading terms cancel. Larger shifted-factor searches can run on the active CPU pool and choose the earliest matching shift.
- The symbolic finite-sum fallback fits a first-order recurrence and checks the resulting expression at three held-out indices. Rational functions of the extra parameter are compared exactly. Expressions with remaining evaluable special functions use numerical checks.
- The direct `taylor` and `laurent` expander generates exact factorial, inverse sine and binomial weights incrementally. Composition uses the lowest power of its argument to bound the required weights. `asinh` and `atanh` use rational Taylor weights when the argument has zero constant term.
- `root_branch` reduces exact integer branch indices modulo a positive integer degree before forming the phase. `sqrt_branch` and degree-two roots use the same parity of the branch index. Direct complex evaluation preserves the side of the square-root cut and rescales extreme magnitudes.
- Finite-group isomorphism and automorphism searches extend the map already checked for each generator prefix. Each trial visits the additional right-multiplication relations and restores the prefix on return. The first isomorphism follows the table order of the candidate images.
- Todd–Coxeter index and order requests check the completed transition table and return the live coset count. `fp_group` checks the relators and the generated action's order against that count before constructing a Cayley table of order at most 720.
- Permutation-group Cayley table construction reuses a permutation buffer for the products in each row. Large tables can construct independent rows on the active CPU pool. Both axes follow the sorted order of group elements.
- F4 processes critical pairs by sugar degree and insertion order within each degree. It checks matrix limits as rows and columns are discovered. Large batches can prepare Macaulay rows in parallel and pass them to elimination in the same order.
- F5 uses the same signature and reduction order across worker counts. Generator normalization and reductions within each large preparation sweep can run independently on the active CPU pool. The signature loop checks the size of its initial basis and checks coefficient sizes when the active polynomial tail changes.
- `apart` decomposes a rational function over the rationals. It computes each denominator factor power's numerator with the polynomial Chinese remainder theorem and emits nonzero pieces in factor order and increasing power. Large decompositions can compute independent factor blocks on the active CPU pool.
- `root_of(k, c0, ..., cn)` uses a zero-based first argument. With exact rational coefficients, it separates overlapping rational enclosures to order distinct real roots before the non-real roots. Independent factors of larger polynomials can use the active CPU pool, and factors with only real roots finish after real isolation.
- `resultant` and `discriminant` use exact polynomial remainders for rational scalar coefficients. Coefficients that are independent expressions use the Sylvester matrix and fraction-free elimination. For large matrices the active CPU pool can update independent rows after each pivot. Both operators reject coefficients that depend on the eliminated variable.
- Algebraic-field norms in real quantifier elimination use the shared exact rational resultant at each interpolation point. The convention is the Sylvester resultant with coefficients in ascending degree. Interpolation retains a zero when the specialized polynomial vanishes and reconstructs the norm through Newton divided differences. Larger sets of independent samples can use the active CPU pool. Field embeddings generate successive powers of the primitive element in the quotient basis. In sufficiently large exact systems, workers update independent rows during elimination.
- `square_free_factors(poly, var)` returns the leading coefficient and the monic rational factors grouped by multiplicity. The factors are pairwise coprime, and the list is in increasing multiplicity. A nonzero constant returns an empty factor list.
- The degree-six and degree-seven Galois resolvent analysis used by `solve` and `solve_complex` reuses fixed-point permutation monomials across candidate groups and coset membership across exponent choices. Independent work can use the active CPU pool. Representative order and the fixed-point multiplication and addition order stay consistent across worker counts.
- Cyclotomic Gauss periods reuse fixed-point unit phases within each conductor and each character's sorted cosets across exponent choices. Large phase tables can use the active CPU pool. Real periods need only cosines.
- Fixed-point Galois root refinement prepares the polynomial and derivative coefficients once and refines independent seeds in their original order. The `groebner` operator uses lexicographic order by default over the rationals. An explicit `grlex` or `grevlex` argument selects another order.
- Symbolic verification checks an exact numeric residual for zero without converting it to a float. Approximate constants and samples of unresolved residuals use their numerical tolerances. A serial check ends at the first finite sample that refutes the claim. Large checks can evaluate the same sample points in parallel.
- `verify_limit(f, x, a, L, [dir])` shares the calculus limit reducer. It compares signed infinity separately from finite results and returns a Boolean. The optional `plus` or `minus` chooses the side and samples that side only.
- Common subexpression elimination keeps declared binder operands within their original scope. `cse_cost` counts exact expanded-tree operations before rewriting and counts each definition and rewritten output afterward. References to a temporary contribute no operations.
- Cut-cell clipping computes simplex fractions from sign-changing edges. The scaled edge ratios preserve fractions when finite values have overflowing differences, and the cell recursion reuses fixed-size local sample storage.
- The affine and projective homotopy solvers share checked degree admission and start order. Affine paths track independently on the active CPU pool. Each adapter enforces its own documented degree and path budgets before creating starts.
- `simple_linear_regression` borrows paired data and scales centered moments when needed. An exact binary accumulator handles widely separated exponents on the scaled path. The native slope carries response divided by predictor units, and the intercept carries response units.
- `LinearRegression::value_and_gradient` shares one residual pass and leases scratch from the numerical pool. On the physical interface the loss has squared response units, the intercept derivative has response units, and each slope derivative has response times predictor units.
- `Dd::sqrt` preserves a low component even when the input lies near the Float range limits. `num_native_dd_hypot` and `num_native_cdd_norm_dd` retain the original physical dimension. `num_native_dd_parts` returns both components separately. `num_native_cdd_recip` scales the complex quotient and inverts its dimension.
- `persistent_homology` processes each simplex at its earliest filtration value and treats signed zeros as one level. The measured ABI returns separate tensors for births, deaths and the essential-interval mask.
- The single-pole real Meijer G path combines `z^b` and `exp(-z)` in logarithmic scale. It can return a subnormal result when that value remains representable.
- The quadratic sieve checks for exact small divisors even when the work budget cannot admit a sieve block. `qs_factor_pair` returns two ordered nontrivial exact factors after verifying their product. Either factor may be composite.
- `PreparedTriangle` reuses triangle geometry for individual rays and shared-direction batches. The measured ABI preserves the coordinate dimension of the ray parameter and intersection point and returns a dimensionless normal. Batch results use a hit mask.
- `Bsr::matmul_dense` applies a block sparse matrix to a row-major matrix of right-hand sides without forming the sparse operand as a dense matrix. Each output is rounded from the exact dot product. The `num_linear_bsr_matmul_dense` operator returns the product of the operands' reference scales and dimensions.
- `sparse_native` applies sparse LU or Cholesky to multiple right-hand sides using a single factorization. The native batch solvers return an array with the right-hand-side dimensions divided by the operator dimensions. The automatic solver also reports the selected factorization.
- General AMG uses one reusable workspace for its V and W cycles. Its native batch preconditioner applies the hierarchy from zero to each input row using the same workspace and preserves the quotient dimension.
- `GeometricMg` visits the active grid colour during red–black smoothing. The V/W and full multigrid solvers reuse residual storage and compare scaled norms when ordinary sums of squares leave the Float range.
- Tensor-train inner products select a two-stage contraction order from the bond ranks and reuse a bounded workspace. Native results carry the product dimension of both trains.
- `tensordot_views` borrows tensor views and packs only operands that cannot be flattened in their existing layout. `num_linear_tensordot` uses the same contraction and keeps the order of uncontracted axes and the product of the two references.
- `SimplexMap` reuses affine geometry for adaptive quadrature and unsigned volume. Its determinant scales the product of pivots before rounding, so opposing extreme axis scales can produce a representable measure.
- Sparse orderings include reverse Cuthill–McKee, approximate minimum degree and nested dissection. `ordering_metrics` measures half-bandwidth and lower profile in one pass over the sparse pattern. `num_native_ordering_metrics` accepts CSR offsets, neighbour indices and a zero-based `perm[new] = old` permutation. The measurements treat each edge as undirected and ignore repetition.
- `pchip_many` and `akima_many` reuse the coefficients of a segment across adjacent queries. They keep input order and support repeated coordinates. Their typed adapters require the queries to share the knots' dimension and preserve the ordinates' dimension.
- `MultilinearGrid` validates rectilinear axes and the flat sample layout once for repeated allocation-free lookups. The session-local `num_native_multilinear_grid_new` and `num_native_multilinear_grid_eval` operators accept axes with independent physical dimensions and restore the sample dimension.
- `real_roots::find_roots_in` searches a finite closed interval and preserves exact roots at its endpoints. `num_native_real_roots_find_roots_in` accepts bounds, tolerance and a positive coordinate reference in the same physical dimension and returns sorted roots in that dimension.
- `brent_with_bracket` returns the root and its final ordered bracket. The measured operator `num_brent_with_bracket` restores the callback's coordinate dimension and reports the actual evaluation count. Exact zeros return a bracket with two identical endpoints.
- `levin_condition_numbers` reuses one recurrence to report a dimensionless condition number for each available transform order. Infinite values indicate an undefined or unbounded condition number. The native operator accepts measured terms with a common dimension and supports the `U`, `T` and `V` variants.
- `sim::symplectic::integrate_sampled` retains the initial, cadence-aligned and final states of a separable symplectic integration. The native binding keeps exact step indices and restores the physical dimension of each position and velocity.
- `ricci_curvature` shares the finite-difference stencil and center metric factorization across the Ricci tensor and scalar. The native operator checks the coordinate and metric references and restores the two distinct result dimensions.
- `SpectralGrid::helmholtz_plan` prepares a periodic Fourier symbol for repeated or batched right-hand sides. The native batch operator accepts forcing in field per length squared and shift in inverse length squared. Compatible singular Fourier modes receive zero amplitude.
- `solve_burgers_nd_with_boundaries` advances cell averages by shared Lax–Friedrichs face fluxes with periodic or zero-gradient outflow boundaries on each axis. The fully periodic solver conserves the sum of cell averages up to roundoff. The checked velocity-frame operator enforces the per-axis CFL bound.
- `direct_field_into` evaluates the softened N-body field in caller-provided storage. The direct field restores source times length to the power `1 - dimension` in the native operators.
- `solve_wave_dirichlet_sampled` advances 2D or 3D homogeneous Dirichlet waves with initial displacement and rate. Retained samples use zero boundary faces from step zero and include the final step. The native operator supports signed steps and restores displacement units.
- `solve_heat_equation_2d_cn_adi_fixed_boundary` keeps the initial edge values fixed through both Crank–Nicolson ADI half-steps. Both 2D variants reuse the tridiagonal factors across steps.
- `NsSolver::divergence_summary` reports maximum and volume-weighted RMS divergence over fluid cells. The native binding preserves inverse-time norms, fluid area or volume, and signed outward flux. `divergence_into` accepts a reusable output slice for the cellwise field.
- The MAC pressure projection selects a pressure reference for every isolated component that has no prescribed pressure. It uses the same reference rows in the matrix and right-hand side, and reuses the factorization when density and the pressure stencil are unchanged.
- `kernels::dense` and `kernels::schur` provide real Schur, generalized Schur, Sylvester and Lyapunov paths. `kernels::lowrank` provides column-pivoted QR, randomized SVD, LOBPCG and Anderson acceleration. `lobpcg` solves ordinary symmetric problems. `lobpcg_generalized` accepts matrix-free stiffness and positive-definite mass operators, returns mass-orthonormal eigenvectors, and can skip search updates for converged pairs while retaining them in Rayleigh–Ritz.
- `kernels::sparse_exact` and the symbolic `sparse_symbolic` family cover elimination over rational, finite and symbolic fields, CRT determinants with a Hadamard bound, Dixon lifting with rational reconstruction and scalar Wiedemann methods. The modular minimal polynomial uses randomized projections. Rank over rational inputs uses rational elimination. Choose the dense exact algorithms when the task needs Smith or Hermite normal forms.
- `kernels::holonomic` and `holonomic_*` cover annihilators, closure under addition, multiplication, powers and differentiation, coefficient recurrences and exact zero tests at an ordinary expansion point. The supported coefficient path uses a single variable and rational Taylor data at zero. Definite sums use the separate telescoping rules. A generated closure annihilator satisfies the requested relation and can have higher order than a global minimal annihilator.
- Numeric finite fields include prime `GF(p)` and `GF(256)`. `Gf256Multiplier` reuses byte products for batch scaling and XOR multiply-add with the same polynomial as Reed–Solomon. The symbolic `gf_*`, `gfx_*` and `gfp_factor` families add extension fields and symbolic factorization.
- Numbered Bessel J and Y use recurrence in suitable parameter regions. Complex asymptotic expansions can lose relative precision close to zeros or with large order relative to the argument. Where residual or component-level accuracy matters, check it against independent values in the regime of interest.
- `carlson_rg` evaluates the symmetric elliptic integral of the second kind. `jacobi_amplitude` retains the accumulated number of periods, and `jacobi_elliptic_batch` shares one parameter plan for all rows of `[sn, cn, dn]`.
- `fresnel_sc_interval` evaluates the sine and cosine integrals over a whole interval, including infinite limits. It resolves differences between adjacent endpoints and far-field tails. `EllipticPiPlan` reuses the complete third-kind integral when evaluating different amplitudes.
- `cartesian_to_spherical` and `spherical_to_cartesian` convert fixed-size triples without allocating in the Rust kernel. The forward map preserves small polar angles near the axis and directions when the radius overflows. The fixed-shape manifest adapters accept a shared length reference and radians.
- `SylvesterPlan` reuses the Schur reductions of fixed coefficient matrices across different right-hand sides. `SylvesterPlan::for_lyapunov` prepares the transposed coefficient pair with one decomposition. The native solver divides the right-hand-side dimensions and reference by those of the coefficients.
- `bessel_in_log_abs` evaluates the logarithm of the magnitude of the integer-order modified Bessel function, including when its original or scaled value is beyond floating-point range.
- `EwaldReciprocalPlan` prepares conjugate wave pairs for a fixed periodic cell, screening and cutoff. Configurations can share the plan while recomputing their own phases, energies, forces and virial. Parallel reductions merge fixed wave blocks in order.
- `SphDensityPlan` retains neighbors and distances for fixed SPH positions and a maximum smoothing length. New densities can use different masses, smoothing lengths or the other supported kernel. The plan includes self and periodic or reflecting image terms. Native density units are mass divided by length to the spatial dimension.
- `Complex::recip` and complex division rescale extreme components and preserve representable results. The reciprocal's manifest contract derives the inverse input dimension.
- `Yee::plane_wave_sample` reads the electric and magnetic values and their times on the normal-incidence TF/SF auxiliary line. The line advances only the causal prefix until it reaches the reserved endpoint. The native adapter restores each field in its own unit.
- `ChebSeries::from_values` builds a second-kind Chebyshev interpolant from existing samples. Large transforms use the shared FFT planning and scratch buffers. Adaptive refinement reuses samples at common nodes, so repeated evaluation at a coordinate must represent the same function value.
- `pic::AssignmentPlan` shares the same periodic linear or cubic weights for deposition and sampling at fixed particle locations. The measured mesh density uses charge per length, while particle samples retain the mesh field's dimension.
- `LinearSplitPlan` retains the Strang or fourth-order Yoshida phases for a fixed real potential, mass and signed time step. Propagation shares FFT plans across successive wave functions on one to three periodic axes. The measured adapter keeps the wave function's inverse square-root volume dimension.
- `L2Grid` retains the square roots of trapezoidal weights for a fixed finite nondecreasing axis. Prepared normalization uses the unrounded scale, including when the rounded norm overflows or underflows. The measured normalization returns no samples for zero measure.
- `JumpDistribution::fill_marks` writes sequential marks into a caller-owned buffer and consumes the same draws as repeated single samples. Fixed jump diffusion reuses one mark buffer and bounds both the expected and the accumulated jump work. The measured batch adapter returns a tensor with one sample per row.
- `Sobol::point_at` reads an indexed unit-cube point, and `Sobol::seek` changes the next position. Quasi-Monte Carlo applies a fixed block reduction and advances Sobol coordinates incrementally within each block.
- `LevinPlan` reuses weighted nodes for a fixed phase, frequency and interval. Supply an amplitude function or values in node order, including measured samples in the manifest adapter. Slowly varying phases use Gauss–Legendre quadrature.
- `eval_value_and_jacobian_terms` and `values_and_jacobian_at_terms` share powers and term products for values and derivatives over the same box or point. Box evaluations preserve outward rounding. The measured Jacobian uses residual per coordinate units.
- `sum_terms_to_infinity` accelerates partial sums from an iterator without exceeding the requested term budget. The sampled prefix adapter reports the measured estimate, heuristic absolute error when available, and consumed term count. `sum_range` includes the final integer even at `i64::MAX`.
- The sparse CSC matrix-vector kernels use live entries even when columns have reserved capacity. They support directly computing either orientation and reusing a caller-owned output buffer. The native destination keeps its own reference, with replacement committed after checks and rescaling.
- `SimplexResidualEstimator` retains connectivity and geometric weights for repeated finite-element state estimates. Constant and variable coefficients share the cached space geometry. In spatial dimension `d`, dimensional indicators have units of the field times length to the power `(d + 2)/2`, divided by time.
- `matrix_norms` evaluates the Frobenius, induced 1- and induced infinity norms together from live sparse CSC entries. Scaled accumulation handles finite norms with extreme input or intermediate scales.
- `kruskal_wallis` and `mann_whitney_u` share pooled ranks and handle ties. Samples may have different group lengths. Degenerate pooled ranks yield a domain error.
- `bell_batch` returns Bell counts in input order using the table of finite values. Native results use `None` for overflow at an individual index. `PrimeSqrtPlan` reuses primality and reduction data for smaller modular roots under one prime.
- `Multivector::mul_central` multiplies a scalar–pseudoscalar element using the algebra's pseudoscalar square. The native operator combines the two operands' physical dimensions and reference scales. Inversion scales the calculation so finite inverses can survive extreme input magnitudes.
- `huber_location_with_scale` uses a positive caller-supplied scale and solves the clipped score with a reusable residual buffer. `num_robust_huber_location_with_scale` requires the sample and scale dimensions to match.
- `Dual::powi_with_second_derivative` returns the normalized power and its derivatives along the dual input's direction. Recovery at extreme scales preserves finite derivatives even when the usual intermediate power overflows or underflows.
- `hessian_diagonal` and `hessian_diagonal_with_steps` evaluate only the coordinate-wise second derivatives. `laplacian` sums the same diagonal samples in coordinate order. The measured callback bindings give each result in output units divided by squared coordinate units.
- `NewtonCgWorkspace` retains Newton and CG buffers for repeated solves. The native tape plan owns its selected objective snapshot and preserves independent physical coordinate, parameter and output references.
- `PolynomialAntidifference` compiles ascending power coefficients once. Its interval method uses a divided difference to resolve small differences between nearby values. The native plan takes a physical origin and positive step, and its values carry the coefficient dimension.
- `indefinite_sum_with_budget` and `indefinite_product_with_budget` check lattice and continuation work before evaluating the callback. They reject non-finite endpoints and out-of-range lattice indices. The measured sum keeps the callback output dimension, and the product operates on positive factors divided by a value reference.
- `randomized_svd` scales extreme sketch columns before orthonormalization. Its native dense adapter writes matrix and transposed-matrix products into the buffers supplied by the decomposition. The singular value reference carries the input matrix dimension.
- `hyp2f1_cplx` evaluates the convergent positive-real Gauss value at one without intermediate Gamma overflow. [NIST DLMF §15.4.20](https://dlmf.nist.gov/15.4.E20)
- `ln_bessel_k` returns the logarithm of the modified Bessel function of the second kind for real order. A centered, scaled integral keeps the logarithm available when the ordinary function underflows or overflows. [NIST DLMF §10.32.9](https://dlmf.nist.gov/10.32.E9)
- The exact Chebyshev functions compute degrees by binary doubling and preserve the rational values at periodic arguments. `chebyshev_tu_mod` computes both residues with full-width `u64` degree and modulus. [NIST DLMF §18.5](https://dlmf.nist.gov/18.5)
- `GeometricMg` supports adjacent-level full-weighting restriction and multilinear prolongation with homogeneous Dirichlet boundaries. The same transfer buffers serve V and W cycles and full multigrid. The native adapters retain the input array's dimension and reference when changing levels.
- The one-, two- and three-stage Gauss–Legendre methods form the Newton matrix using the Jacobian at each collocation stage. `GaussLegendreWorkspace` retains stage buffers, and the convergence test uses the scale of the stage derivatives.
- `Expr::series` truncates exact holonomic powers using a coefficient recurrence. A positive leading degree shifts the series and can put the entire power beyond the requested truncation.
- `deciding_terms` uses exact leading recurrence coefficients and a conservative integer root bound to determine how many initial terms suffice. Its search includes the budget endpoint.
- `fd_jacobian_dense_par` gives each job a reusable perturbed state and writes its columns contiguously. Each derivative evaluation starts with zeroed output and gives the same column bits across thread counts.
- `fd_jacobian_colored_par` reuses perturbed states across colours. For sparse patterns with many colours it retains only the sampled entries needed by the CSR output. Each right-hand-side call receives a zero-initialized buffer.
- `weibull_quantiles` shares validation and scale across lower-tail probabilities. `weibull_inverse_survival` accepts the upper tail directly. The measured bindings return scale units and report a domain error for infinite results.


## Signal processing

- `DwtPlan` retains the filters and boundary layout for same-length single-level wavelet transforms. Its Rust analysis and synthesis methods write to caller buffers. The measured manifest adapters preserve the signal dimension in both coefficient bands.

- `kernels::signal` implements orthonormal DCT-II and DST-II with their inverses using cached FFT plans. The legacy `signal::fft` and `signal::ifft` entry points and FFT convolution use the same plan and scratch pools as `kernels::fft`. Multidimensional real FFTs shrink the Hermitian axis before processing the other axes. Large independent FFT batches and STFT frames can run in parallel with deterministic ordering.
- `welch_psd` averages complete, optionally overlapping windowed frames into a one-sided power spectral density. `welch_cross_spectrum` also returns cross-spectral density using `conj(X) * Y` and magnitude-squared coherence. Coherence is zero in bins where either input has zero power. `inverse_stft` reconstructs a covered interval from full STFT spectra and rejects any sample with no nonzero window contribution. `upfirdn` applies explicit FIR taps without materializing the upsampled signal.
- The typed `num_signal_welch_psd` and `num_signal_welch_cross_spectrum` records carry separate dimensions for frequencies, density and coherence. Frequency bins use the sample rate units. Density is measured per unit frequency, and coherence is dimensionless.
- Welch accumulation partitions large workloads into fixed blocks and combines their spectra in order. `num_signal_autocovariance` centers the samples and divides by the full sample count at every lag. `num_signal_autocorrelation` normalizes by the zero-lag covariance, and `num_signal_partial_autocorrelation` uses the Yule–Walker equations. All return lags `0..=max_lag`. Covariance has squared sample units, and both forms of correlation are dimensionless.
- `analytic_signal`, `hilbert` and `analytic_envelope` use periodic boundaries. `zoom_fft` evaluates uniformly spaced frequencies in cycles per input sample via chirp convolution. Moderate transforms with matching input length, bin count, and frequency step share the convolution plan, even when the start frequency changes. The typed `num_signal_zoom_fft` operator takes and returns a vector of complex samples.
- `kernels::wavelets::wavelet_packet` decomposes both low and high branches into equal-width leaf bands, with the low branch preceding the high branch. `inverse_wavelet_packet` reconstructs a signal from that leaf matrix. `FrftPlan` reuses the eigenbasis of the discrete fractional Fourier transform for multiple orders on signals of the same length.
- One-dimensional real FFTs share their even-length packing and twiddles. Wide strided axes can run in parallel through contiguous batches. The power-of-two complex entry points in `kernels::transforms` preserve their historical scalar radix-2 rounding order.
- `fftconv::convolve_overlap_save` computes full linear convolution in independent blocks. `OverlapSavePlan` reuses the filter spectrum and scales extreme amplitudes before transforming. Its native batch operator accepts flat measured recordings and zero-based row offsets, retains empty rows, and gives the product of sample and tap units. `autocorrelate` returns the nonnegative lags of the linear autocorrelation, starting at the sum of squares.
- `firwin_lowpass` and `firwin_bandpass` design Kaiser-windowed FIR filters with cutoffs normalized to Nyquist. `frequency_response` instead takes cycles per sample, with Nyquist at 0.5. `sos_filter` accepts second-order sections, and `resample_poly` applies centered, rational-rate polyphase FIR resampling.
- The stationary wavelet pair `swt` and `iswt` uses periodic boundaries with one coefficient per sample in every band, including for odd input lengths. Both reuse the approximation buffer between levels and preserve coefficient order across worker counts. `wavelet_soft_threshold` and `wavelet_hard_threshold` denoise detail bands using a threshold in the units of the input samples.

## Weighted graphs

`kernels::graph::Graph` stores directed arcs, including self-loops and parallel arcs. `Graph::from_edges` validates a batch and reserves each adjacency list before insertion. Model an undirected weighted graph with two equally weighted arcs per edge.

| Operation | Contract |
|---|---|
| Dijkstra | Single-source shortest paths with nonnegative weights. |
| Bellman–Ford | Single-source shortest paths with negative weights, rejecting negative cycles reachable from the source. |
| DAG shortest paths | Single-source shortest paths in linear time on directed acyclic graphs, including negative weights. |
| Floyd–Warshall | All-pairs shortest paths in row-major order. A negative matrix diagonal signals a negative cycle. |
| Topological sorting, strong and weak components | Edge weights are ignored. Strong component labels follow topological order. Weak component labels follow the smallest vertex in each component. The symbolic SCC operator shares the iterative strong-component traversal. |
| Multi-source BFS and condensation | BFS reports the nearest-source hop count, with no distance for an unreachable vertex. Condensation returns topologically numbered strong components and deduplicated edges between them. |
| Articulation points and bridges | Takes one endpoint pair per undirected edge and preserves parallel edges. Returns cut vertices and bridge endpoints. |
| Prim's minimum spanning forest | Preserves all components and isolated vertices of an undirected input represented by symmetric arcs. |
| PageRank | Counts each outgoing arc separately and redistributes dangling mass uniformly. |
| Dinic maximum flow and minimum cut | Uses finite nonnegative capacities and distinct terminals. Returns the flow value and a Boolean mask for the source side of a minimum cut. |

The `num_native_graph_*` handles retain the physical dimension of edge weights. Bulk construction takes a two-column endpoint matrix and a rank-one weight tensor. Path records return `distances` in coherent edge units and `previous` as optional predecessor indices. Unreachable distances are positive infinity. Maximum flow returns its `value` in coherent capacity units and a dimensionless `source_side` mask. Native weighted graphs allow up to 256 vertices and 65,536 arcs. The maximum-flow call further limits `V² E` to 50 million. Consult the manifest for the callable names and typed schemas.

## Low-rank matrices

`kernels::lowrank::interpolative_decomposition` runs truncated column-pivoted QR to approximate a matrix using its original columns and a dimensionless coefficient matrix. The actual rank can fall below the requested maximum on rank-deficient input. `num_linear_interpolative_decomposition` accepts a native matrix handle and returns the selected column indices and the coefficients in original column order.

## Dimensions and grids

`solve_transport_sampled_nd` keeps the initial state, snapshots at the requested
step interval, and the final state if it falls between intervals. Its typed
adapter `num_grid_dimensional_solve_transport_sampled_nd` counts retained
snapshots separately from the work required to advance through all steps.

Symbolic heat, wave, Laplace and Poisson equations use one operator per family. The problem determines its spatial dimension, and compatibility aliases include `_1d`, `_2d` and `_3d`. Finite-difference families such as `heat_fd`, `wave_fd`, `poisson_fd` and `advect_fd` infer spatial rank from the input shape on the unit box. Boundary-aware variants accept Dirichlet or Neumann faces. Pure-Neumann Poisson checks source and outward-flux compatibility and returns a zero-mean result. The method-of-lines helper targets one-dimensional grids. Consult the explicit method for its supported boundary conditions.

For a disk or ball of positive radius, `pde_poisson_integral(g, radius, dimension)` extends angular boundary data throughout the interior. It returns constant data unchanged and reduces a single integer-frequency disk sine or cosine to a closed form. General data use definite integrals whose bound variables are distinct from parameters in the datum.

`sim::dimensional` uses x-fastest flat fields with axes `[nx]`, `[nx, ny]` or `[nx, ny, nz]`. The shared transport paths support advection, diffusion and their combination. The Poisson paths provide relaxation and multigrid. Other solvers include wave, Euler, geometric fields and scenario-specific simulation drivers. Scenario dimensions, field layouts and method options are part of the live scenario catalogue. Verification compares against analytical solutions, dimensional reductions, symmetry, convergence order or conservation, using `tests/sim/dimension_coverage.rs` and `tests/kernels/dimension_coverage.rs`.

The fixed-step and adaptive scalar finite-volume solvers share the same reconstruction and flux evaluation for all four schemes. They reuse work buffers across steps and keep callback evaluations in cell order. The adaptive solver controls temporal error on a fixed grid. Classical Lax–Friedrichs may require a looser tolerance because its numerical viscosity depends on the timestep. See `tests/fvm_facade_reuse.rs` and `tests/pde_adaptive.rs`.

## Selecting a callable interface

Literal term operators under `rules::numeric` accept numbers, lists and method symbols. An unresolved input or failed precondition can leave the call symbolic. Use `Session::apply_diag` to inspect reported numerical rejections. The expression-level families cover robust statistics, Fourier and wavelet transforms, `coherence`, `wavelet_packet`, `inverse_wavelet_packet`, sparse iterative solves, exact integer convolution, tensor decompositions, sampled functions, polynomial roots and grid solvers. Where indices enter the interface they are zero-based. The native numerical manifest exposes the cosine and sine transforms, analytic signal, Hilbert transform, amplitude envelope and zoom FFT under `num_signal_*`.

The typed numerical ABI additionally exposes checked records, tensors and session-owned models. It supports reusable CHOL/LU and multigrid state, tensor-train algebra, complex transform data, checked homotopy certificates and ODE/SDE objects with solver-specific controls. Discover the exact callable names and signatures in `KernelManifest` or Aevia's `aevia rssn` output. Native methods that accept Rust callbacks or borrow host storage also remain available directly. ## Statistics

`num_descriptive_quantiles` uses type-7 interpolation. `num_robust_quantiles` accepts all nine Hyndman–Fan definitions, and `num_robust_weighted_quantiles` inverts the weighted empirical CDF. Each batch shares an ordered sample, returns results in query order, and preserves the sample units. `num_robust_ecdf_batch` requires matching sample and query units and returns probabilities.

`bootstrap_ci` returns percentile intervals and `bootstrap_basic_ci` reflects the percentile bounds around the statistic of the observed sample. Both use a seeded resample stream and return a lower and upper bound for finite normalized data. The median, MAD, and IQR paths evaluate large batches across the active workers and reuse resampling storage. Aevia exposes both operations in `Rssn_Numeric`.

`num_descriptive_histogram` derives uniform edges from the sample. `num_descriptive_histogram_edges` accepts strictly increasing finite edges in the sample's units, allowing the same bins to be used across datasets. Both count interior edges in the bin above and include the highest edge in the final bin. The explicit-edge operation requires every observation to fall within the supplied range. Large samples with a modest number of bins use private counters that merge to the same integer counts for any worker count.

`num_stats_ext_adjust_p_bh`, `num_stats_ext_adjust_p_by`, and `num_stats_ext_adjust_p_holm` adjust dimensionless p-values in their original order. Benjamini–Hochberg controls the false discovery rate under independence or positive regression dependence of null tests. Benjamini–Yekutieli allows arbitrary dependence. Holm controls the family-wise error rate.

`num_native_online_covariance_push_batch` accepts a row-major observation matrix with the dimensions of the accumulator. It commits only after the entire batch succeeds, combining large shards in a fixed order regardless of worker count. `num_native_online_covariance_correlation` returns a dimensionless Pearson correlation matrix, or `None` if any column is constant or there are fewer than two observations. `num_distributions_multivariate_normal_log_pdfs` factors the covariance once for all query rows and requires data normalized to a common dimensionless reference.
